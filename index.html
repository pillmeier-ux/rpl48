RPL·48 – Kurzanleitung

Ein RPN/RPL-Rechner nach dem Vorbild des HP 48GX. Zahlen kommen auf den Stack, Befehle arbeiten mit den Ebenen 1:, 2: …

Grundlagen

  • 3 ENTER 4 + → 7. Ein Operator schließt die Eingabe automatisch ab.
  • ENTER ohne Eingabe = DUP, ⌫ ohne Eingabe = DROP, ► ohne Eingabe = SWAP.
  • ▼ bearbeitet Ebene 1, ▲ öffnet den interaktiven Stack (ECHO, PICK, ROLL …).
  • ◄ (lila) und ► (grün) wählen die Zweitfunktionen über den Tasten.
  • ON = ATTN: bricht Eingabe/Fehler ab. ► EVAL = UNDO.
  • Tippe auf das Display, um die Handy-Tastatur zu öffnen (Namen, Programme schneller eintippen). Am Computer funktioniert die normale Tastatur.

Variablen

  • 5 'A' STO speichert. Der Name erscheint im VAR-Menü.
  • VAR-Softkey: drücken = ausführen/abrufen, ◄+Softkey = speichern, ►+Softkey = RCL.
  • ' öffnet Anführungszeichen und schaltet α ein. α schaltet Buchstaben ein/aus, ◄ im α-Modus = Kleinbuchstaben.

Programme (RPL)

  • ◄ ÷ setzt « ». In einem Programm werden Befehlstasten als Text eingefügt (Anzeige PRG).
  • Strukturen: IF … THEN … ELSE … END, CASE, IFERR, start end FOR i … NEXT/STEP, START … NEXT, WHILE … REPEAT … END, DO … UNTIL … END
  • Lokale Variablen: « → a b « a b * » » oder « → r 'π*r^2' »
  • Beispiele im VAR-Menü: HYP, FAKT, FIB, KREIS.

Objekte

Zahlen, komplexe Zahlen (1,2), Strings "abc", Namen 'X', Algebraische 'X^2+1' (symbolisch rechnen, EVAL, →NUM), Listen { }, Vektoren [ ], Programme « ».

Menüs

MTH (Mathe), PRG (Stack, Objekte, Verzweigungen, Tests, Listen, Strings, Speicher), CST (eigenes Menü aus der Liste in Variable CST), VAR. NXT blättert, ◄ NXT zurück. ◄ MTH = Modi (STD/FIX/SCI/ENG, DEG/RAD/GRAD).

Stack und Variablen bleiben in diesem Browser gespeichert. Ein unabhängiges Fan-Projekt, inspiriert vom HP 48GX.
